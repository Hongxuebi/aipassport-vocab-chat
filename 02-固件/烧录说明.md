# 烧录说明（ESP32-C3 + ST7789 + 3 键 + TF 卡）

> 目标：从"快递拆开"到"屏幕上跳出一张单词卡"，大约 1 小时。
> 第一次做先**只接屏和三个键**，跑通再上 SD 卡和电池——一次接一堆，出问题不知道是哪根线。

---

## 1. 装 Arduino 环境

1. 装 [Arduino IDE 2.x](https://www.arduino.cc/en/software)
2. 文件 → 首选项 → 附加开发板管理器网址，加：
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
   （国内下不动就看 `https://www.arduino.cn/thread-91658-1-1.html` 里的镜像，或直接用离线包）
3. 工具 → 开发板 → 开发板管理器 → 搜 `esp32`（Espressif Systems）→ 装
4. 库管理器装这四个：
   - `Adafruit GFX Library`
   - `Adafruit ST7735 and ST7789 Library`
   - `ArduinoJson`（v7；装的是 v6 就把 `JsonDocument doc;` 换成 `DynamicJsonDocument doc(8192);`）
   - `DFRobotDFPlayerMini`（P3 加音频时才需要）

**开发板选**：`ESP32C3 Dev Module`
**其它设置**：Flash Size 4MB、Partition Scheme `Default 4MB with spiffs`、上传速度 921600

## 2. 接线

| 屏/模块 | 引脚 | C3 |
|---|---|---|
| TFT | SCLK | GPIO4 |
| TFT | MOSI(SDA) | GPIO6 |
| TFT | MISO | GPIO5 |
| TFT | CS | GPIO7 |
| TFT | DC | GPIO1 |
| TFT | RST | GPIO2 ⚠️ **并一个 10k 到 3V3** |
| TFT | BL（背光） | GPIO10 |
| TFT | VCC | 3V3 |
| TFT | GND | GND |
| 键·翻面 | 一端→GPIO0，一端→GND | 内部上拉，不用外接电阻 |
| 键·不认识 | GPIO20 ↔ GND | |
| 键·认识 | GPIO21 ↔ GND | |
| TF 卡 | CS | GPIO8 |
| TF 卡 | SCK/MOSI/MISO | 与屏共用 4/6/5 |
| 喇叭（P3） | DFPlayer TX → GPIO3 | 单向，只发指令 |

### ⚠️ 三个"启动脚"的坑（接错了表现为"电脑识别不到串口"）

C3 上电那一刻会看 **GPIO2 / GPIO8 / GPIO9** 的电平，决定进不进下载模式：

- **GPIO2 必须为高** → 接 TFT_RST 的话，务必 10k 上拉到 3V3
- **GPIO8 必须为高** → 接 SD_CS 没问题（SPI 的 CS 天然上拉），别接成按键
- **GPIO9 不能为低** → 别拿来接按键或下拉电阻

如果插上电脑没串口：先拔掉 GPIO2/8/9 上的东西试一次，能认出来就说明是这里的问题。

## 3. 改固件里的四行

打开 `单词机\单词机.ino`，顶部改：

```cpp
#define WIFI_SSID   "你家WiFi"          // 2.4G！C3 不支持 5G
#define WIFI_PASS   "密码"
#define SERVER_URL  "http://LAN_HOST:8791"   // 跑「服务」那台机器的内网IP
```

屏幕如果是 1.8" 的 ST7735，改成：

```cpp
#define SCR_W 128
#define SCR_H 160
#define USE_ST7789 0
```

内网 IP 怎么查：Windows `ipconfig`，macOS `ipconfig getifaddr en0`。

## 4. 先把"卡包"准备好

在电脑上（`01-词库` 目录）：

```bash
python 单词机.py 排程 词库模板.csv 进度.json --新词 10
python 单词机.py 出图 今日队列.json ..\03-卡片包 --主题 小学 --每日一句 "今天真棒"
python 单词机.py 服务 ..\03-卡片包 --词库 词库模板.csv --进度 进度.json --端口 8791
```

**TF 卡格式化成 FAT32**（32G 以下默认就是 FAT32），把 `03-卡片包` 里的
`manifest.json`、`c\`（整个抄）放到卡根目录。这样第一次开机即使没网也能显示。

> 不手动拷也行，设备第一次会自己从 WiFi 下——只是慢一点。

## 5. 烧录 + 第一次开机

1. USB 插上，开发板选好，端口选好，点上传
2. 串口监视器 115200，能看到 `卡片 9 张，包日期 2026-10-22`
3. 屏幕顺序应该是：`mount sd ...` → 进度条同步 → 第一张卡的正面

### 正常的表现

- 按 GPIO0 那颗键 → 翻到背面看意思
- 按 GPIO20 → "不认识"，跳下一张
- 按 GPIO21 → "认识"，跳下一张
- 两分钟不动 → 熄屏（light sleep），再按任意键回来，**还是原来那张**

## 6. 出问题怎么查（按这个顺序，别跳）

| 现象 | 先查这个 |
|---|---|
| 电脑不认串口 | GPIO2/8/9 被拉低了；换根**能传数据**的 USB 线（很多线只有电） |
| 屏幕白屏/花屏 | 先跑 Adafruit 库自带的 `graphicstest` 例子；花屏多半是 MISO/MOSI 接反或 SPI 速度太高 |
| 屏幕有字但偏色/上下颠倒 | `tft.setRotation(n)` 试 0~3 |
| 屏幕内容只显示了一部分 | `SCR_W/SCR_H` 和实际屏对不上（240×320 vs 135×240 等变种） |
| `SD 挂不上` | 卡不是 FAT32；或 CS 接错；或卡座没插紧 |
| 显示"缺文件" | 卡里没有 `c\*.rle`，或者 manifest 里的文件名对不上 |
| 同步一直转圈 | `SERVER_URL` 的 IP 不对 / 电脑防火墙挡了 8791 / 手机也开一下 `http://IP:8791/` 验证服务在不在 |
| 按了没反应 | 按键另一端没接 GND；或内部上拉没生效（用 `pinMode(x, INPUT_PULLUP)` 已经在代码里） |
| 醒来还是黑屏 | 背光脚（PIN_BL）在 `sleepNow()` 里没恢复——检查 `digitalWrite(PIN_BL, HIGH)` 有没有执行 |

**一条万能技巧**：`服务` 那个终端里会打访问日志（加 `-v`）。设备到底有没有来拿图，看日志就知道，
不用猜。

## 7. 电量与充电

- TP4056 的 `OUT+ / OUT-` 接 C3 的 `5V / GND`（不要接 3V3，板上有 LDO）
- 电池别接反，TP4056 反接会烧
- 估算：亮屏 10 分钟/天约 40mA，其余时间 light sleep 约 0.2mA
  → 500mAh 大约 **2 周**，实测为准
- 想加电量显示：电池正极串 100k/100k 分压到 GPIO9（ADC），代码里读一下就行
