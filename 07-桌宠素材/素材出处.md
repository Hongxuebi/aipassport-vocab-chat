# 桌宠素材的出处与许可

> 这一页只讲**东西从哪来**，不讲怎么做。做法的账在 `改造方案-AI-Passport.md`。

## 一、开机动画（boot splash）

| 环节 | 事实 | 证据 |
|---|---|---|
| 出处 | GitHub **`lxj5820/dsh-boot-animation`**（310 星，仓库 License 显示 `NOASSERTION`）里的 `assets/videos/3.mp4` | 远端 `3.mp4` 的 git blob sha1 = `ac74e18fba0f9ce1230b651f9d513cd5d2d728d8` |
| 下载 | 2026-10-20 15:05（经 jsDelivr 取回），本地存为 `whale-girl.mp4`，5,195,581 B | 本地文件 git blob sha1 与远端**逐字节一致** |
| 用途 1 | 当 DSH（本 Agent 的网页界面）启动动画 | `~/.dsh/boot-animation/_disabled/whale-girl.mp4` |
| 用途 2 | 切出 8 秒片头 `whale-fantasy-intro-8s.mp4`（3.0 MB），取右侧女孩的脸 | `~/.dsh/boot-animation/videos/` |
| 上设备 | 裁 `(1180,211)-(1664,856)` → 抽 27 帧 @6fps → PackBits 打包 459 KB → 烧到 boot 分区 `0x6D0000`，播放时 2× 最近邻铺满 240×320（4.5 秒） | `改造方案-AI-Passport.md` §10 |

**许可状态**：上游仓库自带 License 为 `NOASSERTION`（未声明），画面本身是第三方美术/动漫人物。
**因此**：本仓库**不随附**这一段动画的任何画面（帧图、预览页、帧包已全部移除），只保留"怎么打包/怎么解码"的代码与文字说明。
自用设备上烧录的帧包不对外分发；若要对外发布固件，需先换成本项目自产的画面。
